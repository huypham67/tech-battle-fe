# Tech Battle FE

React + TypeScript + Vite frontend for Tech Battle.

## Commands

```bash
npm install
npm run dev
npm run build
npm run lint
```

## Structure

```text
src/
├── api/          # HTTP client and endpoint definitions
├── components/   # Reusable, data-agnostic UI
├── context/      # Client-side session and room state
├── data/         # Temporary mock data
├── hooks/        # React hooks for server and client state
├── lib/          # Framework-independent helpers
├── screens/      # Route-level screens
├── styles/       # Global tokens and styles
└── types/        # Shared TypeScript models
```
